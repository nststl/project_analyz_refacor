# Вимоги та симуляція предметної області

## 1. Проблема, яку вирішує система

Публічна бібліотека веде облік **примірників книг**, **позик читачів**, **черги резерву** на популярні видання та **фінансових санкцій** за порушення терміну повернення. Потрібно:

- передбачувано нараховувати **штраф** залежно від тривалості прострочення та категорії книги (**Strategy**);
- коректно вести **чергу резерву** (пріоритет за часом постановки) і **сповіщати** наступного читача, коли з’являється вільний примірник (**Observer**);
- дозволяти **бібліотекарю** тимчасово **блокувати** читача;
- застосовувати **автоматичне блокування** за політикою при великій заборгованості.

У навчальній симуляції сховище даних — **in-memory** (без зовнішніх БД).

## 2. Актори

| Актор | Опис |
|-------|------|
| **Читач** | Резервує книгу, бере позику, повертає книгу; підпадає під штрафи та блокування. |
| **Бібліотекар** | Керує блокуванням читача (адміністративна санкція). |

## 3. Ключові сценарії (Use Cases)

1. **UC-01 Видача книги** — читач бере доступний примірник, зменшується `available_copies`, створюється активна позика з дедлайном.
2. **UC-02 Повернення вчасно** — читач повертає до дедлайну, штраф 0, примірник знову доступний.
3. **UC-03 Повернення з простроченням** — нараховується штраф за календарні дні після дедлайну (Strategy).
4. **UC-04 Резерв у черзі** — якщо читач хоче популярну книгу, він стає в **FIFO**-чергу; дубль одного читача на ту саму книгу заборонено.
5. **UC-05 Сповіщення про наявність** — після повернення примірника, якщо є черга, фіксується подія для наступного читача (Observer).
6. **UC-06 Блокування бібліотекарем** — бібліотекар встановлює `blocked_until`, читач не може брати нові позики.
7. **UC-07 Автоматичне блокування** — після великої заборгованості/прострочення застосовується політика тимчасового блокування.

## 4. Бізнес-правила (скорочено)

- **Ліміт активних позик** на читача — параметр `max_concurrent_loans` (за замовчуванням 3).
- Книги категорії **REFERENCE** не видаються назовні (in-library only).
- **Штраф**: календарні дні після `due_at`; сума залежить від стратегії та категорії книги.
- **Черга резерву**: порядок за зростанням `sequence` (монотонний лічильник у репозиторії).
